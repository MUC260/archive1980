## 统一风格提示句（任务书 3.9）

> **1980年代中国县城档案馆的做旧纸质文件，泛黄纸张，轻微折痕污渍，扫描件质感，自然光影，无现代元素，画面干净，细节真实。**

## 三、豆包生图要点（照这个做，出错率最低）

1. **一张图一段提示词，整段复制**，不要一次让豆包生成多张——多张时它会把不同图的要求混在一起，文字必然出错。
2. **比例要在提示词开头就写清**（「竖版」「横版16:9」「正方形1:1」），并在豆包的画幅选项里同步选 3:4 / 4:3 / 16:9 / 1:1。
3. **文字类图片必须单列文字清单**：借书卡、索引卡、值班日志、信纸这四张（外加破图的「图片加载失败」、信纸角的「183」、印章和 Logo 的馆名），提示词里都已经写好了这一行：
   > `画面中必须出现且不得出错的文字：……`
   生成后**逐字比对**这一行，错一个字就重生成，不要将就。
4. **生成后必查清单（按图）**：
   | 图 | 必须核对的关键字 |
   | --- | --- |
   | `loan-card-front.jpg` | 陈望、秦巴壹、1980.8.4 |
   | `loan-card-back.jpg` | 除角落印章外不应有字；印章为 1980·8·4 |
   | `book-cover.jpg` | 基础气象观测（竖排五字）、气象出版社 |
   | `index-card.jpg` | 陈望、781、1980年8月4日、失踪，档案未结 |
   | `duty-log.jpg` | **183**、陈望、钟叔、基础气象观测 |
   | `letter-page.jpg` | **陈望、781、1980年8月4日、山洪**（最重要） |
   | `broken-image.jpg` | 图片加载失败 |
   | `letter-corner.jpg` | **183** |
   | `paper-texture.jpg` | 不得有任何文字 |
   | `seal.jpg` | 秦巴县、档案馆（六字齐全） |
   | `logo.png` | 秦巴县档案馆（圆弧六字） |
   | `archive-room.jpg` | 不得有任何文字、不得有现代物品 |
5. **中文手写体是豆包最容易翻车的地方**（长段落尤其）。`letter-page.jpg` 建议一次生成 2–3 张候选，挑错字最少的；错 1–2 个字可以用修图工具擦掉重写，错得多就重生成。
6. **统一色调**：如果某张图明显偏白、偏冷或过于鲜艳（不像放旧的），把开头那句统一风格提示句再追加一次，或补一句「整体偏米黄发褐、不要鲜亮色彩」。
7. **去底**：`seal.jpg`、`logo.png` 生成后如果是白底，用抠图/「白色变透明」工具处理一下，再放进 `assets/images/`，前端叠加时更自然。
8. **像素规格**：豆包出图通常是 1024 级别，拿到后按上表「目标像素」等比缩放/裁切即可（网页对尺寸不敏感，但保持比例别变形）。
